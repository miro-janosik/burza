== Stahovanie ==
 Gear mage 'mail attachment dowloader', v maile mam licenciu na verziu 3.
 Free verzia 2.4 ide na XP hned, verzia 3.0 vyzaduje na XP instalovat .net 4.0
 Downloader nefunguje cez wine, treba to spravit cez VirtualBox XP
 Na XP-ckach treba nakonfigurovat sietovy adapter - vid 
 http://askubuntu.com/questions/232876/how-to-let-a-virtualbox-guest-running-windows-access-the-internet
 Ak by nesiel spustit VirtualBox tak treba na stroji cez right-click v lavom zozname na 'discard current state', a potom zrusit share.

Downloaded files to excel:

Downloader - set to download files with following name:
(date)_(id)_(filename)

Set it to move files from one folder to another (requires IMAP)
Files that are not moved probably do not contain attachment, or it can't be downloaded by Downloader
Go to webmail.mcsrdiecko.sk and download attachments there manually.
 
== Ako premenovat subory tak, aby boli pekne citatelne vo formate 'ID.pripona' ==

- ls > list.txt

^(.*_ID\((\d*(_\d)*)\)_.*(\.\w*))$
with: 
mv "\1" "\2\4"

- bash list.txt
