== When making free codes for sellers ==

* Get list of existing sellers from web + their codes into CSV.
  It should be already cleared up from sellers from previous year that did not attend, to free up codes.
	web-manage/getWebSellerCodes.pl - produces web_codes.txt
	
* Get additional new codes for new sellers into CSV (and send it for handout of codes)
	genCodeList web_codes.txt

* Add new codes to web DB
	web-manage/addNewCodesToWebFromCsv.pl

* Update web DB - remove items that are sold.
	web-manage/deleteSoldItems.pl
	If items are not marked as sold on web, then use scripts below

== After sellers filled items on web ==

* See statistics and remove inactive sellers
	web-manage/webSellerStats.pl
	web-manage/webRemoveEmptySellers.pl

* Copy data from web DB to sale DB

	web-to-sale/web-to-sale.pl

== Sale - when verified items and sellers for sale, before sale ==

* Find sellers with items not on sale (they did not arrive for sale). These items and sellers are deleted from sale DB.
	sale-manage/s_fixSellerStatus.sh
	sale-manage/s_removeItemsNotIn.sh
	sale-manage/s_removeSellersWithoutItems.sh

	XX categories
	sale-manage/ts_sale_updateItemCats.sql

* (not required:) Sync web DB with sale DB (sellers and items). Only removes sellers and items that were not brought to sale.

	sale-to-web/alignWebWithSale.pl
	What it does:
		- lists which sellers differ on web/in sale
		- removes extra sellers from web that are not in sale
		- updates seller names on web if they did not have name and have it in sale
