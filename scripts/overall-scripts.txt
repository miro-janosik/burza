== Preparing new codes ==

* Get list of existing sellers from web + their codes into CSV.
  It should be already cleared up from sellers from previous year that did not attend, to free up codes.
	web-manage/getWebSellerCodes.pl - produces web_codes.txt which contains login with password and a name.
	
* Create additional new codes for new sellers into CSV (and send it for handout of codes)
	web-manage/genCodeList web_codes.txt
		(generates codes.csv)

* Add new codes to web DB (uses local file codes.csv)
	web-manage/addNewCodesToWebFromCsv.pl

* check if new sellers have 'info' filled in (error in older script), fix by SQL:
	web-manage/sellersMissingCodeFix.sql
