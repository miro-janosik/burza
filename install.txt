Windows:
Instal packages:
gtkmm-win32-devel-2.16.0-2.exe
pqxx: more complicated. Libraries are present, but in case of problems they
have to be recompiled. You need PostgreSql8.3 and libpqxx-win32.32368.zip which
contains sources with msvc solution. If you build shared DLLs they have some problems
running (stack corruption on connecting to DB), but building static DLL works
if you add dependencies: wsock32.lib Ws2_32.lib , prefix PQXX_PQ_STATIC and set Burza to MDd.

Linux:
Install packages:
pqxx
you can compile the package by installing "postgresql-9.1.0-1-windows.exe" and getting 
libpqxx-win32 (from lib dir or from http://www.kirit.com/libpqxx-win32)


tery.install.txt

so you want to use .so library from internet.
first - library is probably not stored in system path.
use 'locate thatlib.so'. If nothing is printed - it is not in the system.
Add it:

sudo ln -s $PWD/libmylib.so.666 /usr/lib/libmylib.so

then fix up the locator:

sudo updatedb

and test locator

locate libmylib.so

you can also try to see if its dependencies are met:

ldd libmylib.so

That's it.
